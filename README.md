# Learn Web Development Indonesia

Repository ini merupakan pusat pengumpulan tugas praktik dan proyek pembelajaran dari program **Learn Web Development Indonesia** yang dipandu oleh **Rhein Sullivan**.

Melalui repository ini, setiap peserta dapat mengumpulkan hasil pengerjaan tugas, mendokumentasikan proses pembelajaran, serta membagikan proyek website yang telah dikembangkan.

Pembelajaran disusun secara bertahap mulai dari dasar pengembangan web menggunakan HTML, CSS, dan JavaScript hingga pembuatan proyek website secara mandiri.

## Tujuan Repository

1. Menjadi pusat pengumpulan tugas seluruh peserta Learn Web Development Indonesia.
2. Mendokumentasikan perkembangan kemampuan peserta dalam mempelajari Web Development.
3. Melatih peserta menggunakan Git dan GitHub dalam pengelolaan proyek.
4. Membiasakan peserta menulis dokumentasi proyek menggunakan Markdown.
5. Mendorong peserta membangun portofolio melalui proyek yang telah dikerjakan.
6. Menjadi ruang apresiasi dan publikasi hasil karya peserta.

## Struktur Repository

Setiap tugas akan disediakan dalam folder tersendiri. Peserta wajib membuat folder atas nama masing-masing di dalam folder tugas yang bersangkutan.

Contoh struktur repository:

```text
learn-web-development-indonesia/
│
├── README.md
│
├── tugas-1/
│   ├── README.md
│   ├── nama-peserta-1/
│   │   └── README.md
│   ├── nama-peserta-2/
│   │   └── README.md
│   └── nama-peserta-3/
│       └── README.md
│
├── tugas-2/
│   ├── README.md
│   ├── nama-peserta-1/
│   │   └── README.md
│   └── nama-peserta-2/
│       └── README.md
│
├── tugas-3/
│   └── ...
│
└── tugas-selanjutnya/
    └── ...
```

Struktur tersebut merupakan contoh. Folder tugas akan ditambahkan mengikuti perkembangan materi pembelajaran.

## Ketentuan Pengumpulan Tugas

Setiap peserta wajib mengikuti ketentuan berikut:

1. Buka folder tugas sesuai dengan nomor tugas yang sedang dikerjakan.
2. Buat folder baru menggunakan nama masing-masing. Gunakan huruf kecil dan tanda hubung jika nama terdiri dari beberapa kata.
3. Masukkan file proyek hasil pengerjaan ke dalam folder tersebut.
4. Buat file `README.md` di dalam folder peserta.
5. Isi file README dengan identitas peserta, deskripsi singkat tugas, tautan repository proyek, dan tautan demo website.
6. Pastikan repository proyek dapat diakses secara publik.
7. Pastikan tautan demo dapat dibuka dan menampilkan hasil pengerjaan dengan baik.

## Format Dokumentasi Peserta

Gunakan format Markdown berikut untuk file `README.md` di dalam folder masing-masing.

```markdown
# Nama Peserta

## Informasi Peserta

- Nama:
- Username GitHub:
- Tugas:
- Materi:

## Deskripsi Proyek

Tuliskan penjelasan singkat mengenai proyek
yang telah dikerjakan.

## Repository Proyek

[GitHub Repository](LINK_REPOSITORY)

## Live Demo

[Demo Website](LINK_DEMO)

## Media Sosial

- Instagram:
- TikTok:

## Catatan

Tuliskan kendala, pengalaman, atau hal baru
yang dipelajari selama mengerjakan tugas.
```

## Publikasi Hasil Karya

Selain mengumpulkan tugas melalui GitHub, setiap peserta dianjurkan untuk membagikan hasil pengerjaannya melalui media sosial, khususnya Instagram dan TikTok.

Ketentuan publikasi:

1. Unggah screenshot, rekaman layar, atau video demonstrasi hasil pengerjaan.
2. Sertakan penjelasan singkat mengenai tugas dan materi yang telah dipelajari.
3. Tag akun Instagram dan TikTok **@rheinsullivan**.
4. Gunakan hashtag yang relevan dengan pembelajaran Web Development dan Learn Web Development Indonesia.
5. Pastikan hasil karya yang dipublikasikan merupakan hasil pengerjaan sendiri.

Hasil karya peserta yang menandai akun tersebut berkesempatan untuk di-repost sebagai bentuk apresiasi, dokumentasi, dan motivasi bagi peserta lainnya.

## Etika dan Ketentuan Kontribusi

- Kerjakan setiap tugas secara mandiri sesuai materi yang telah dipelajari.
- Tidak diperkenankan mengambil atau mengklaim hasil pekerjaan orang lain sebagai karya pribadi.
- Gunakan penamaan folder dan file yang jelas serta konsisten.
- Jangan mengubah atau menghapus pekerjaan peserta lain.
- Periksa kembali hasil pengerjaan sebelum mengirimkan kontribusi.
- Apabila menemukan kesalahan pada struktur repository, sampaikan terlebih dahulu kepada pengelola.

## Penutup

Belajar Web Development bukan hanya tentang memahami teori dan menulis kode, tetapi juga tentang membangun kebiasaan, menyelesaikan permasalahan, mengelola proyek, serta mendokumentasikan hasil pekerjaan.

Manfaatkan repository ini sebagai tempat untuk belajar, berlatih, bereksperimen, dan menunjukkan perkembangan kemampuan kalian.
